# UI & Typography Guidelines

## Strictly Prohibited Patterns

### Prohibit Eyebrow Pills & Sparkle Badges
- **Never add rounded pill badges or bubble tags** (`border-radius: 9999px`, 1px border, background glow, and Lucide icons like `Sparkles`, `Compass`, `Zap`, `Star`) above section headings.
- This pattern is a recognized hallmark of generic AI-generated templates.
- Maintain an authentic, bespoke luxury aesthetic: let headlines lead with confidence and clean typography hierarchy.
