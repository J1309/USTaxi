# UI & Design System Guidelines for USTaxi (Lavender Taxi)

## CRITICAL DESIGN RULE: Strictly Prohibited Elements

### 1. NO EYEBROW PILLS / KICKER BADGES / SPARKLE CAPSULES
* **STRICTLY PROHIBITED**: Never use rounded pill badges, bubble capsules (`border-radius: 9999px`), or kicker tags with icons (such as Lucide `Sparkles`, `Compass`, `Star`, `Zap`, etc.) above section headings or titles.
* **Why**: This pattern is widely recognized as a generic AI-generated website trope ("AI Slop Badge" / "SaaS Sparkle Pill"). It cheapens the brand and screams "templated AI site."
* **What to do instead**:
  * Let the primary `<h2>` section headline stand cleanly on its own with strong typography hierarchy and proper spacing.
  * If context is strictly needed, use clean, unboxed, subtle uppercase text without any pill background, without any border, and without any decorative sparkle/mini-icons.
